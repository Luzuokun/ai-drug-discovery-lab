# Install & environment

Get a reproducible workstation, then run campaigns through [reinvent-agent](https://github.com/Luzuokun/reinvent-agent). This Lab is the manual — not a second installer.

## Recommended path

1. **Agent environment** — follow the reinvent-agent README (conda/mamba, CUDA, REINVENT, docking, GROMACS as needed).
2. **First molecule** — [REINVENT4 · 01 Installation & First Molecule](../molecular-generation/reinvent4/01-installation-first-molecule.md).
3. **HITL gates** — [How it works](../how-it-works.md), then open the [Workbench](../stations/index.md).
