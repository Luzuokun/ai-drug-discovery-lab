# 你 You（PI）工位

**职责：** 批协议、签声称、选下一刀。你是公司 CEO，也是科学签字人。

## 你掌握的闸门

| 旗标 / 动作 | 何时 |
|-------------|------|
| `--approve-run` | 新的 REINVENT / 采样预设 |
| `--approve-dock` | 新受体 / 盒子 |
| `--approve-literature` | 新的 PubMed 拉取 |
| MD / 多糖批准 | 新时长或协议包 |
| shortlist 签字 | 「值得合成 / 值得买」 |
| 外发摘要 | 任何离开实验室的内容 |

## 决策面（Portfolio）

跨模态 shortlist（`output/portfolio/shortlist.csv`）与一页战役卡是路线图 Decision MVP——仍用人写权重预设，不是自动 CRM。

落地前：读 Critic HTML、对接/MD 表，以及 [战役案例](../campaigns/index.md)。

## 永不交给模型

- 写 `reinvent.toml` 或整份 mdp
- 发明靶点、盒子或文献
- 宣布湿实验建议
